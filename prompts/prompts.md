### Context
We are building a Pomodoro app that has the following functions as mentioned in "H3 Instructions"

### Instructions
Build the main page of a pomodoro timer web app.
–  Use only HTML and CSS — implement the UI only
–  HTML layout:
    –  An h1 tag with the title "Pomodoro"
    –  Below it, the current remaining time
    –  Below that, Start / Stop / Reset buttons
    –  Below that, a button that goes to the settings page
–  Keep the CSS for styling in an index.css file

THEN:
Use JavaScript to add features to the main page.
–  Start button: an event handler that starts the timer
–  Stop button: an event handler that stops the timer
–  Reset button: an event handler that resets the timer to 25 minutes
–  Set the event handlers using the onclick approach
–  Keep all the JavaScript code in a separate index.js file

THEN: 
Build a brand-new settings page.
–  Use only HTML and CSS — implement the UI only
–  HTML layout:
    –  An h3 tag with the title "Setting"
    –  One input tag for setting the timer minutes
    –  A done button
–  Keep the settings page CSS in a separate setting.css file
–  Make the main page's settings button navigate to this settings page (do not change its styles)
