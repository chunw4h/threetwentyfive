Instructions
Mission: Build Your Own Web Project!

Apply what you've learned about HTML, CSS, JavaScript, and Claude Code to plan, build, and deploy your very own web project from scratch.

Requirements

    Brainstorm and choose a topic you are genuinely interested in.
    A single-page application is sufficient, but building a multi-page site is highly encouraged.
    Use only vanilla HTML, CSS, and JavaScript (do not use any external frameworks or libraries).
    Keep your project organized within its own dedicated folder.
    Deploy your finished project to Netlify and secure a publicly accessible URL.

Step-by-Step Workflow Guide

    Break it down: Tackle the project in small, manageable chunks. Instruct Claude Code sequentially: Main Page UI → Main Page Functionality → Additional Pages UI → Additional Functionality.
    Write prompts in Markdown: Save your instructions in markdown files (e.g., inside a prompts/ folder). This makes it much easier to track, modify, and reuse your prompts.
    Review frequently: Test your output in the web browser after every single step. If you don't like the result, modify the prompt and fix it immediately before moving on to the next feature.

Project Idea Hints

    To-Do List App
    Flashcard / Vocabulary Quiz
    Simple Calculator or Currency Converter
    Personal Bookmark / Link Directory
    Expense Tracker or Workout Logger

Tip: Don't aim for absolute perfection right out of the gate. Start small with a basic, working version, and gradually add features step-by-step.

How to Submit Please submit the live Netlify URL or screenshots of your completed project!
